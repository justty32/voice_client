# org：誰管哪塊、下一棒給誰

回 [wf](../README.md)。

工作流（[WORKFLOWS.md](../../WORKFLOWS.md)、`workflows/`）講一種工作怎麼做；這個夾只講：這件事歸誰、做完交給誰。別處已有的規矩（[AGENTS.md](../../AGENTS.md) 的 always-on 規則、驗證要求、維護鏈）只連過去，不抄。

**什麼時候讀**：決定一件事交給誰、開或關座位、掛下屬或單工、改交接方式。
**不在這裡找**：怎麼操作 aos（aos 知識庫、[wf/aos](../aos/README.md)）、一種工作怎麼做（[WORKFLOWS.md](../../WORKFLOWS.md)）。

## 使用者說的

使用者 2026-11-23 原話：

- 「我希望以後就是只有你作爲窗口，然後這個repo的主要工作者都是fsm」
- 「事情都盡量交給agent做」「agent可以再派agent做事，模型隨意。可以隨意push。」
- 腦：「不，只使用fsm gpt系列，先都用sol...開發用astra。」
- 座位切法選 (a) dev＋docs 兩座：「2.a，之後再細切。」
- 其餘九選一律照窗口推薦：「3.都照推薦。」

九個選擇的答案與來源在 [CHOICES.md](CHOICES.md)。標「（提案）」的是起草時補的細節，使用者還沒確認。

## 座位

| 座位 | 誰 | 一句話 | 狀態 |
|---|---|---|---|
| [lead](lead/README.md) | `main` | 使用者的窗口：派工、驗收、活狀態 | 已掛 |
| [dev](dev/README.md) | `dev` | 產品程式碼、`tests/`、CODE_MAP | 有工作才掛，尚未掛過 |
| [docs](docs/README.md) | `docs` | `docs/`、`README.md`、`workflows/`、`plans/`、`reports/` | 有工作才掛，尚未掛過 |

座位＝這個夾裡的一張卡，加上它管的地盤。三個都在子 daemon `repo-vc`；agent 名 `dev`、`docs` 是提案。定義在 [wf/aos/defs/](../aos/README.md)。有工作才掛，見 CHOICE 2。雜活不開座位，由窗口派單工，見 [helper](helper/README.md)。空白卡 [seat](seat/README.md) 留著當樣板。

考慮過、沒開的：測試、審查、雜活座位（使用者 2026-11-23 選兩座，「之後再細切」）。之後細切時從 dev 或 docs 的地盤切出去，表上那列和卡一起改。

## 標準流程

```
使用者 -> lead（聽懂、先說計畫）
   |- 有座位管          -> 那個座位（沒掛就由窗口掛上）
   |- 沒座位管          -> lead 派單件工作
   '- 查證、雜活        -> 單工（helper）
-> 做的人自己先驗 -> 在自己地盤 commit、push -> 最終狀態回 lead
-> lead 看證據 -> 回報使用者
```

### 窗口與權限

- **只有一個窗口**：只有 lead 跟使用者說話。方向題從誰手上冒出來，都以 `NEEDS-USER` 交給 lead。沒有人替使用者選。
- **授權**：刪檔、往外送東西要使用者親口說。push 已有使用者 2026-11-23「可以隨意push」。agent 的信不是授權。
- **看證據，不看宣稱**：檢查的人讀檔、讀輸出。光一個 `DONE` 什麼也不證明。

### commit、檢查、別人的改動

- **誰 commit**：各座位在自己地盤內 commit，只 add 明確路徑，事後回報窗口；出地盤、刪檔、動到跑著的 agent 先問窗口（CHOICE 4）。
- **獨立檢查**：窗口看證據；動到 Python 時 `.venv/bin/python -m pytest -q` 全綠是硬門檻；大改另派不同實例讀來源；同一處 3 輪不過停下問使用者（CHOICE 5）。
- **不是你做的改動**：地盤外的照常；自己地盤內出現陌生改動停下問窗口；不 revert 別人的改動（CHOICE 6）。

### 下屬與例外

- **下屬**：座位可以開下屬，腦只從 llm kernel 的 gpt 系包挑；下屬不給能擴權的工具；交接書寫死上限（預設 2），配額往下不倍增；閒時自我改進不做（CHOICE 8）。
- **小事可以跳步**：地盤內一兩行的修正直接交該座位，仍要回最終狀態。
- **沒有規矩管到時**：風險低、能還原就做，回覆裡說理由，lead 事後看；不確定或不能還原就先問。
- **固定步驟做成工具，要判斷才開 agent**。
- **座位之間可以直接寫信**，請對方做它地盤內的事；接的人照樣回最終狀態，並知會 lead。典型：dev 改了使用者看得到的行為，寫信請 docs 更新手冊。
