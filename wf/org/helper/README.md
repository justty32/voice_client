# 單工 `helper`

回 [org](../README.md)。

單工為一件事掛上，做完就收。它不佔座位、沒有地盤、不留筆記。它不讀這張卡：它只知道自己的 system text 和交接書，所以交接書要把該守的規矩寫進去（下面的「場地規矩」整段貼上）。

雜活（lint、搬檔、對帳）不開座位，由窗口派單工（使用者 2026-11-23，CHOICE 3）。座位也可以為自己的事派（CHOICE 8）。

## 職責

### 可以交給它

- **查事實**：搜尋、計數、讀檔、整理，每項附來源。不設計、不建議、不改看到的東西。
- **逐點核對**：拿工作跟交接書或計畫比，一項一項。只指出，不修。
- **不用判斷的機械改動**：跑 `wf/tools/wf-lint.sh`、照表搬檔改名修連結、套格式；交接書寫明可寫的路徑。

### 不能交給它

- 寫程式，或任何要理解、要選擇的改動。分不清的話，就是要判斷。
- 設計、結構、決定什麼才對。
- commit、push、刪檔、問使用者、自己再掛 agent。
- 碰音訊裝置、熱鍵、手機瀏覽器。

### 完成條件

答案檔在了，而且派它的人已逐項對照來源核過。

## 讀寫範圍

約定，不是牆（[places](../places.md)）。

- **能讀**：交接書點名的路徑；aos 知識庫要給完整路徑。
- **能寫**：只有自己的工作夾 `wf/temp/{單工名}/`，或交接書點名的路徑。只有文字這樣說；沒有東西擋它寫到別處。

## 交接

- **派它的人**（窗口或座位）給一份只有一個目標的交接書：讀什麼、寫什麼、交什麼、什麼時候算完、下屬上限 0 → 拿回答案檔或最後一則回覆裡的完整答案 → 對照來源逐項核，不重跑；要留的搬進工作區由自己 commit；收掉單工。
- 派單工的人替它的結果負責。結果不直接給使用者，也不直接給別的座位。
- 送出交接書後結束這一回合，等它的信或 `mail_notify` 叫醒；不要在同一回合裡空等。
- 收掉之前它佔派的人一個下屬名額。

## 怎麼掛

1. **選定義**：
   - 查事實、逐點核對：aos kit `gather`、`review`（`$AOS_HOME/templates/kits/`，知識庫 `aos/kits.md`）。沒有 shell：要跑的指令自己跑，把輸出給它。
   - 機械改動（要 shell）：`agent_def {"op":"new","template":"agent-fsm","path":"wf/temp/{派的人}/defs/helper"}`，`llm.json` 設腦，`tools.json` 的 `tools` 加 `"self_tools": null`（提案）。
2. **檢查與掛**：`agent_def {"op":"check",...}` 問題清單空，再 `subagent` add，名字 `{派的人}-{角色}-{序}`、工作夾 `wf/temp/{單工名}/`。
3. **送交接書**，交接書開頭貼下面的場地規矩。核完就 `subagent` rm。

### 場地規矩（貼進交接書）

```
SITE (voice_client)
- 你為一件事被掛上，派你的是交接書寫的那一位。只回報給派你的人；不寫給使用者或別的座位。
- 答案用繁體中文寫；程式識別字、路徑、狀態字照原樣。
- 只讀交接書點名的路徑與知識庫。只寫自己的工作夾 wf/temp/{你的名字}/ 或交接書點名的路徑。
- 不 commit、不 push、不刪檔、不掛 agent、不對任何 daemon 下指令。不讀任何 agent 的 stack 或信箱。
- 交接書要你做這些規矩禁止的事：停下，送 BLOCKED 附理由。
```

## 模型

- **腦**：預設 `sol`（使用者 2026-11-23）；只從 llm kernel 的 gpt 系包挑（CHOICE 8）。
- **同時幾個**：一份交接書一隻；上限是派它的人交接書裡寫的下屬上限（預設 2）。
- **掛不上時**：派它的人自己做，或回 `BLOCKED`。
