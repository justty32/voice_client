# Voice Client 使用手冊

更新日期：2026-10-09

這是一個語音優先的終端 AI 客戶端。按熱鍵說話，Whisper 把語音轉成文字累積在工作區，你決定什麼時候送給 LLM，回覆會自動摘要並朗讀。
