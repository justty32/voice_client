第 01 章

準備與第一次開機

做菜前要先買菜。小幫手也要幾樣工具，還要知道 AI 住在哪。

先準備三樣東西

  1. 麥克風和喇叭：給耳朵和嘴巴用。
  2. 系統套件（Manjaro / Arch）： 
    sudo pacman -S --needed python portaudio ffmpeg espeak-ng
    portaudio 讓它能錄音，espeak-ng 讓它能說話，ffmpeg 給手機模式轉換聲音。
  3. Python 套件： 
    python -m venv .venv
.venv/bin/pip install -r requirements.txt

告訴它 AI 住在哪裡

小幫手自己不是 AI，它是寄信給 AI 的信差。打開 config.ini，在 [LLM] 寫上 AI 的地址和名字：

[LLM]
model = qwen/qwen3.5-9b
base_url = http://localhost:1234/v1

小提醒　用 LM Studio 或 Ollama 在自己電腦跑 AI 時，地址通常是 http://localhost:…。第一次只要改這一段，其他都有預設值。

第一次開機

.venv/bin/python main.py

狀態列出現「待機」就準備好了。第一次比較慢，因為速記員要先「讀書」：把語音辨識模型載入記憶體。

要離開時打 /exit，它會把每個房間的燈關好再走。
