它裡面怎麼運作

給想改程式的人：小幫手的內部是一間郵局。

一間郵局

小幫手裡有很多房間（模組）。房間之間從不直接講話，只寫信：

  1. 每個房間有寄件匣（Outbox）和收件匣（Inbox）。
  2. 信封寫 topic（寄給哪類收件人），裡面放 payload（內容）。
  3. 郵差（Exchange）一次拿一封，照 topic 放進收件匣。

這叫 Data Tunnel（資料隧道）：房間只要懂信的格式，所有信都經過同一個郵差，查問題只看一處。

信封上的字只寫在一個地方

protocol/topics.py（有哪些 topic）、payloads.py（信長什麼樣）、commands.py（指令和熱鍵）。測試會比對程式、文件和這裡，改錯就紅燈。

房間在哪裡

speech/耳朵、速記員、嘴巴
ui/鍵盤、輸入、畫面、KDE 入口
llm/寄信給 AI、寫摘要
domain/托盤、對話筆記本
modules/指令總管、聊天流程
core/郵局本身
app_wiring/build_core() 蓋好整棟樓
mobile/只換門口，裡面同一棟樓

自己探險

python workflows/common/code-map/codemap.py topics   # 誰寄、誰收
.venv/bin/python -m pytest -q                         # 改完跑測試
