指令和對話筆記本

打字下命令、用嘴巴下命令，還能把對話分成好幾本筆記本。

斜線指令

打 / 開頭就是下命令，忘了就打 /help。

/copy　/paste托盤和剪貼簿互通，貼上時一行一段
/export 名　/import 名把托盤存成檔案、再讀回來
/clear ui只清畫面，托盤不動

完整清單在使用手冊的指令章。

用嘴巴下指令：F7

按 F7，說「發送」，再按 F7。小幫手聽懂「發送」就是 /send。 「清除」「顯示」「停止」「複製」「切換」都聽得懂，說英文 send、clear 也行。

對話筆記本

對話可以分成好幾本，一本聊工作、一本聊旅行，每本都自動存檔。

/new 旅行開新的一本；不取名就叫 session_1、session_2…
/switch 旅行翻到那一本
/list看有哪幾本
/history看這本寫過什麼

小提醒　名字重複時會說「對話已存在」，不會蓋掉舊的那本，要翻過去請用 /switch。
