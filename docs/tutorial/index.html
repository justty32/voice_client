Voice Client 入門手冊

一個會聽、會寫、會幫你寄信給 AI、還會把回信唸出來的小幫手。十分鐘上手。

想像一間小辦公室

  • 耳朵負責聽（錄音）。
  • 速記員把聲音寫成字（語音辨識，STT）。
  • 托盤放著寫好的字，等你決定要不要寄（工作區）。
  • 信差把字寄給 AI（LLM），嘴巴把回信唸出來（語音合成，TTS）。

一張小抄

說話變文字按 F8 說話，再按 F8
寄給 AI按 F9，或打 /send
別唸了按 F10，或打 /stop
再聽一次原文按 F6
看托盤打 /show
忘了指令打 /help

喜歡讀純文字？同一份內容的 markdown 版在 README.md；完整細節在使用手冊。
