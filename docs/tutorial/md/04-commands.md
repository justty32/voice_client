# 4. 用指令和對話筆記本

## 斜線指令

在輸入框打 `/` 開頭的字，就是在對小幫手下命令。忘記有哪些就打 `/help`。
上一章已經用過 `/show`、`/send` 了，其他常用的：

- `/copy`：把現在的托盤複製到剪貼簿。`/paste`：從剪貼簿貼進來，一行一段。
- `/export 檔名`：把托盤存成檔案。`/import 檔名`：再讀回來。
- `/clear ui`：只清畫面，托盤裡的東西還在。

完整清單在[使用手冊的指令章](../../user_manual/commands.md)。

## 用嘴巴下指令（F7）

手不方便的時候，連指令都可以用說的：

1. 按 **F7**，說出指令，例如「發送」。
2. 再按 **F7**。
3. 小幫手聽懂「發送」就是 `/send`，幫你寄出。

聽得懂的字很多，像「清除」「顯示」「停止」「複製」「貼上」「切換」，說英文的 send、clear 也行。

## 對話筆記本

和 AI 的對話可以分成好幾本筆記本，例如一本聊工作、一本聊旅行。每一本都會自動存檔，關機也不會不見。

- `/new 旅行`：開一本叫「旅行」的新筆記本。不取名字就叫 `session_1`、`session_2`……
- `/switch 旅行`：翻到「旅行」那本。
- `/list`：看有哪幾本。
- `/history`：看這一本寫過什麼。

> 名字重複的話，小幫手會說「對話已存在」，**不會**把舊的那本蓋掉。要翻過去請用 `/switch`。
