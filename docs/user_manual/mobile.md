# 使用手冊：手機模式

[使用手冊入口](../user_manual.md)

## 10. 手機模式

1. 啟動：`python mobile_server.py`（需要 `ffmpeg` 轉檔手機錄音；缺少時啟動 log 會報錯，錄音無法辨識）
2. 終端會顯示連線網址（例 `https://192.168.x.x:8080`），手機和電腦要在同一個 WiFi
3. 自簽憑證會有安全警告：點「進階」→「繼續前往」
4. 手機上可錄音（伺服器端 Whisper 辨識）、看回覆、瀏覽器原生語音朗讀

手機與桌面共用同一套指令與工作區流程，指令文案、工作區規則與桌面一致（見[指令](commands.md)）：

- 工作區為 `buffer`、`stt`；`chat` 只能看（`/ws chat` 會提示用 `/history`），`/del`、`/move`、`/to_top` 只作用於當前工作區。
- 錄音辨識與輸入的文字只進**當前**工作區（預設 `buffer`）；切到 `stt` 後才寫進 `stt`。
- `/switch` 不帶參數且沒有 `default` 時會自動建立；`/import` 必須給檔名。
- LLM 錯誤回覆以 `[錯誤] …` 系統訊息顯示並朗讀，狀態列回「待機」（與桌面相同）；音訊轉檔失敗顯示 `[錄音錯誤] …`。
- 沒有 `/exit`（手機無法關閉伺服器）；`/copy`、`/paste` 走瀏覽器剪貼簿。
- 錄音由瀏覽器按鈕控制；沒有 F7 語音指令模式與 F6 重播（伺服器只接受 `QUICK_SEND`、`FORCE_STOP_TTS` 兩種熱鍵訊號）。
- 伺服器停止時若 `buffer` 有內容，會自動存到匯出目錄的 `_buffer_temp.json`（可用 `/import _buffer_temp` 取回）。

同一時間只服務一條連線：新的瀏覽器分頁或重新連線會取代舊連線（舊頁面被斷開），
之後的訊息只送到最新的連線。

`[MOBILE]` 可設定 host、port、ssl。**SSL 建議開著**，現代手機瀏覽器要 HTTPS 才讓用麥克風。
